# プロセスグループの検証

[English](./README.md)

`procgroup` は Linux と macOS のプロセス識別、対象を絞ったスナップショット、
グループの検査と停止を担当します。デーモンの実行状態、設定、実行ユーザーの解決、
制御ソケットの接続元認証には依存しません。

- `Snapshot` は記録済みリーダーの PID と、そのグループの全プロセスを保持します。
- `Inspect` はカーネルの生成時識別情報、ユーザー、リーダーのコマンド、
  観測済みメンバーを検証します。リーダーの不在やゾンビだけのスナップショットだけでは、
  グループの停止を確認したことにはなりません。
- `Stop` は単一のコールバックで検証済みメンバーを**シグナル送信前に永続化**し、
  TERM を送信して猶予期間中に検査を繰り返し、必要なら KILL を使います。
  キャンセルや検査・永続化のエラーが発生した場合は処理を中断します。

呼び出し側はライフサイクルの状態を `Group` に変換します。`AllowUnlaunched` は
起動前に限り識別情報の不在を許容し、`Done` は実行完了を表します。
`Command` は期待するリーダーコマンドの部分文字列です。呼び出し側は `Stop` の
コールバックで受け取ったメンバーを永続化してから成功を返す必要があります。

`ProcessIdentity` は既存の `pid`、`pgid`、`uid`、`started` の JSON フィールドを維持し、
復旧用の保存済みレコードの形式を変えません。
